# Contributing to the discussion

This repository is an independent discussion RFC, not an approved Kleros protocol. Start with [RFC-0001](rfcs/0001-decision-agent-courts.md), then use an issue for a counterexample, design alternative, source correction, or proposed experiment.

Please identify the relevant section, state the assumptions of your argument, and explain what change or test would address it. Concrete state transitions, payoff examples, and controller-level attack scenarios are especially useful. Distinguish existing protocol behavior from proposed behavior and an executed result from an evaluation plan.

Editorial corrections and clarifying pull requests are welcome. Substantive mechanism changes should be discussed in an issue first. A future revision will record which decisions changed and why; examples and hypotheses are not frozen protocol requirements.

Do not submit credentials, private case evidence, proprietary prompts or code, production configurations, unpublished operational data, or material you lack authority to share. Public source references are preferable to copying third-party documents.
